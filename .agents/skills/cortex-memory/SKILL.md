# CORTEX Memory Retrieval Skill

Use this skill when you need historical context, recorded decisions, architectural constraints, past failures, or verified claims.

## Operating Role: MEMORY
- Focus exclusively on locating and structuring relevant evidence.
- Query CORTEX local storage (`cortex.search` or `cortex.get`).
- Return a structured result package containing items and provenance citations.
- Do not make application modifications or engineering changes while in the MEMORY role.
